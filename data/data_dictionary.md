# Data Dictionary

> **Synthetic data**, generated by `python/generate_sample_data.py` (seed 42, ~185 base sessions/day, 1 Jan – 30 Jun 2025).
> Volumes: 35,822 sessions · 25,729 visitors · 160,474 events · 913 valid transactions (after cleaning).
> Generation method: daily Poisson volumes with growth, weekly and campaign effects; per-session funnel progression
> drawn from stage probabilities that depend on channel, campaign, device and landing page; ~28% returning visitors.
> 18 types of data-quality defects are then injected and logged in `data/raw/generation_metadata.json`.

## Raw files (`data/raw/`, never modified)

### sessions.csv: one row per session (contains injected duplicates)
| Column | Type | Description |
|---|---|---|
| session_id | text | Session identifier (`S` + 7 digits) |
| visitor_id | text | Cookie-level visitor identifier |
| session_start | text (timestamp) | UTC; mixed formats `YYYY-MM-DD HH:MM:SS` and `YYYY-MM-DDTHH:MM:SSZ` |
| traffic_source | text | e.g. google, facebook, newsletter, (direct). Contains case/alias variants |
| marketing_medium | text | organic, cpc, paid_social, social, email, referral, (none). Contains variants |
| campaign | text | Campaign name; empty for non-campaign traffic (expected) |
| device_category | text | desktop / mobile / tablet; variants and some missing |
| country | text | Visitor country; some missing |
| landing_page | text | First page path; some with UTM query strings or trailing slashes |
| engaged_session | 0/1 | GA4-style engaged-session flag |

### events.csv: one row per tracked event
| Column | Type | Description |
|---|---|---|
| event_id | text | Event identifier |
| session_id | text | Parent session (some orphans) |
| event_timestamp | text (timestamp) | UTC, mixed formats |
| event_name | text | session_start, page_view, product_view, add_to_cart, begin_checkout, purchase (+ variants) |
| page_path | text | Page where the event fired |
| product_id | text | `P001`–`P025`; only on product_view / add_to_cart |

### transactions.csv: one row per order record
| Column | Type | Description |
|---|---|---|
| transaction_id | text | Order identifier (`T…`; QA orders `TEST…`) |
| session_id | text | Session in which the order was placed |
| transaction_timestamp | text (timestamp) | UTC, mixed formats |
| revenue | number | Order value in USD (some negative = errors) |
| currency | text | USD (some lower-case) |
| transaction_status | text | completed, refunded, test (mixed case) |

## Cleaned files (`data/processed/`)
`sessions_clean.csv`, `events_clean.csv`, `transactions_clean.csv`: same columns as raw, standardised, de-duplicated,
typed. `quarantine_events.csv` / `quarantine_transactions.csv`: excluded rows + `quarantine_reason`.

## Model tables (`data/processed/model/`: loaded by SQL and Power BI)

### fact_sessions (grain: session)
| Column | Description |
|---|---|
| session_id (PK), visitor_id, session_start, country | As cleaned |
| session_date_key | FK → dim_date (yyyymmdd of session_start) |
| traffic_source_key / device_key / landing_page_key | FKs → dimensions |
| engaged_session | 0/1 |
| page_views | Count of page_view events in the session |
| reached_session … reached_purchase | **Ordered funnel** stage flags (0/1); hierarchical by construction |
| has_product_view_event … has_purchase_event | Event present anywhere in the session (unordered; diagnostics) |
| purchase_sequence_violation | 1 if a purchase event exists but not after checkout |
| is_purchasing_session | 1 if the session has ≥1 valid transaction |

### fact_events (grain: event)
event_id (PK), session_id, event_timestamp, event_date_key, session_date_key, event_name, page_path, product_id,
traffic_source_key, device_key, landing_page_key (session attributes copied for direct dimension filtering).

### fact_transactions (grain: valid transaction)
transaction_id (PK), session_id, transaction_timestamp, transaction_date_key, session_date_key, traffic_source_key,
device_key, landing_page_key, revenue (> 0, USD), currency, transaction_status (completed/refunded), is_refunded.

### Dimensions
| Table | Key | Attributes |
|---|---|---|
| dim_date | date_key | date, year, quarter, month_number, month_name, year_month, month_start, week_start, day_of_week(_number), is_weekend |
| dim_traffic_source | traffic_source_key | traffic_source, marketing_medium, campaign, channel_group, source_medium |
| dim_device | device_key | device_category, device_label, device_sort (incl. `unknown`) |
| dim_landing_page | landing_page_key | landing_page, page_type (Home, Collection, Product, Blog, Campaign, Search) |
| dim_funnel_stage | stage_order | stage_name, event_name (disconnected helper for funnel visuals) |

### Channel grouping rule
organic → Organic Search · cpc → Paid Search · (none) → Direct · paid_social → Paid Social · social → Organic Social ·
email → Email · referral → Referral.
